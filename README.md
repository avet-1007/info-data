## 🌟 About

**info-dada** is a project designed to provide users with structured and useful information in a convenient format. The name says it all: *info* — information, *dada* — we give it! 😄

## ✨ Features

- ⚡ **Fast access** to information
- 🎨 **Nice interface** in pixel-art style
- 🔍 **Convenient search** through data
- 📱 **Responsive design**
- 🌐 **Open source**

## 🚀 Installation

```bash
# Clone the repository
git clone https://github.com/avet-1007/info-data.git

# Go to the project folder
cd info-data
```

## 📂 How to open the HTML file (Mini Guide)

You don't need any complicated setup — just follow these steps:

### 🖱️ Method 1: Double-click (easiest)

1. Open the project folder on your computer
2. Find the file `index.html`
3. **Double-click** it — it will open in your default browser 🎉

### 🌐 Method 2: Open with a specific browser

1. **Right-click** on `index.html`
2. Choose **"Open with"**
3. Select your browser (Chrome, Firefox, Edge, etc.)

### 💻 Method 3: Using the terminal

```bash
# On Windows
start index.html

# On macOS
open index.html

# On Linux
xdg-open index.html
```

### ⚡ Method 4: Live Server (for developers)

1. Open the project in **VS Code**
2. Install the **Live Server** extension
3. Right-click on `index.html` → **"Open with Live Server"**
4. The page will auto-refresh on every change 🔥
